# Agents, skills, and pi distributions

[Research index](README.md) · [Applied guidance](../guides/distribution.md)

README bodies, related docs, and manifests were read on 2026-11-10. Default-branch links can change. Packages were not installed or executed. An omission means absent from the inspected README, not necessarily undocumented everywhere.

| Source | Observation | Application |
| --- | --- | --- |
| [Claude Code](https://github.com/anthropics/claude-code) | Separates installation paths and links update/removal docs | Lifecycle depends on distribution |
| [Codex](https://github.com/openai/codex) | Distinguishes CLI/IDE/app and routes to authentication/docs | Match surface and first authentication |
| [Anthropic Skills](https://github.com/anthropics/skills) | Individual skills, plugin bundles, and host paths | Distinguish a skill from its distribution unit |
| [Matt Pocock Skills](https://github.com/mattpocock/skills) | Managed/copy installation, duplicate risks, initial setup | Explain installation through invocation and effects |
| [pi-mcp-adapter](https://github.com/nicobailon/pi-mcp-adapter) | Configuration sources and built-in setting restoration | Removal may need more than reversing installation |
| [pi-web-access](https://github.com/nicobailon/pi-web-access) | Different capabilities for pi and separate MCP usage | Separate distribution-specific requirements |
| [pi-extensions](https://github.com/tmustier/pi-extensions) | Catalog links to component READMEs | Root helps selection; components explain use |
