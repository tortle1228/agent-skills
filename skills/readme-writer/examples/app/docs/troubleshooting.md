# Export troubleshooting

[English README](../README.md) · [한국어](../README.ko.md)

For the fictional design: if no file is produced, check that at least one note is selected and that the destination is writable. A canceled folder picker produces no export. If a same-named file exists, ask the user to choose another name rather than silently overwriting it. These are proposed behaviors, not tested implementation facts.
