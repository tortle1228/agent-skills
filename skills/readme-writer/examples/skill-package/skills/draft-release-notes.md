# Draft release notes: component overview

[Package README](../README.md)

This is a description of a fictional skill, not instructions to execute in this repository.

**Input:** a reviewed list of changes and a release version.

**Result:** a draft organized into additions, fixes, and compatibility changes, followed by questions requiring maintainer confirmation.

**Use when:** a maintainer already knows which changes belong in a release.

**Do not use when:** release scope is unknown or publishing authorization is needed.

**Side effects:** none in this design. No scripts, changelog writes, tags, or publication. A real host may send input to its model provider.
