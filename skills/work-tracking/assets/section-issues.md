## Work tracking

- Planned work lives in GitHub Issues (`gh`), not in roadmap, TODO, or backlog files.
- Labels: `roadmap` (next), `backlog` (parked), `when-needed` (waits on a trigger).
- Title as `Area: sentence`. Body: Why, Steps, Unresolved questions, References.
- Record a finding once, as an issue comment or in the commit body. Do not copy it into this file or other documents.
- Create issues and labels only when asked.
