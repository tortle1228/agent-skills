## Work tracking

- Planned work lives in `ROADMAP.md`: one line per item, with a link when detail exists. Check items off when done and delete finished items once the file passes about 100 lines.
- Record a finding in one place only: a code comment, a commit body, or one note linked from its roadmap line. Do not mirror it into this file or other documents.
- Create no other tracking documents (ADR, research, changelog) unless asked.
